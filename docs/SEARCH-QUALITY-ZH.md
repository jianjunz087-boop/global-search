# 睫毛企业搜索筛选更新

新的 Google/Yandex 获客任务默认启用以下规则：

- 自定义关键词仍附加睫毛业务词；排除 .cn 和主要中国供应商平台。
- 依据搜索返回标题、摘要和网址判断睫毛业务相关性，不使用查询词或目标国家冒充企业证据。
- 不相关页面、教程/招聘等非企业内容不进入新客户列表。
- 有明确中国厂家/供应商、自述位于中国主要产区、公开中国联系电话等证据的结果不进入新客户列表。
- 中国平台结果默认排除；英国进口商仅提到从中国采购不会因此被判为中国卖家。
- 任务详情列出被过滤的网址和原因。历史客户不自动删除。

限制：这是公开搜索摘要的规则筛选，不是企业注册所在地认证。所在地未知的卖家可能仍被保留；企业也可能同时从事其他美妆业务。应检查官网经营范围和地址。返回数量可能减少，不会自动追加付费搜索补足数量。规则不影响已有客户的定向联系方式查询、人工导入和旧版兼容接口。

更新方法：关闭旧服务，下载本次版本并解压，复制旧项目的完整便携 Node 文件夹和私密 .env.local，运行 START-WINDOWS.bat。启动器仍使用原来的 LocalAppData 数据目录。先备份数据；无需把密钥发到聊天里。重新发起搜索以应用规则，旧客户不会自动清理。
