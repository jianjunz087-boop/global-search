三步，开始使用。

无需技术背景，也无需额外安装运行环境。

01

下载安装文件

点击 Windows 下载按钮，保存 .exe 文件到电脑。

02

双击并完成安装

选择安装目录，按提示完成安装，从桌面快捷方式启动。

03

先体验，再连接搜索

先用模拟数据体验功能，再在菜单中配置自己的 SerpAPI 密钥。

安装后就能搜索真实客户吗？

默认仅展示模拟数据。真实搜索需要有效的 SerpAPI 账户与密钥，并按其服务条款使用；客户身份及公开联系方式需要人工核实。缺失的邮箱和 WhatsApp 不会被编造。

客户资料保存在哪里？

桌面版的数据保存在当前 Windows 用户的应用数据目录。通过应用菜单可打开数据文件夹；备份前请先关闭应用。卸载会保留数据。SerpAPI 密钥由 Windows 用户凭据机制加密保存。

会自动群发消息或绕过网站限制吗？

不会。应用不提供 WhatsApp 自动群发或网站限制绕过功能。当前客户评分为演示规则，开发信为模板，尚未接入真实 AI。请遵守来源网站条款及适用的隐私和营销规定。
