# 全球假睫毛 B2B 获客升级：使用说明

这次升级复用原有项目和深绿色界面。原有 Google 搜索、客户跟进、开发信、导出、市场情报页仍保留。新增代码没有清空、重建或删除客户数据库；兼容性迁移增加证据与任务表。你电脑上的真实客户库不在云端，因此更新前仍应自行备份。

## Windows 更新

1. 关闭原项目命令窗口。备份本机 `.env.local` 和 `%LOCALAPPDATA%\BaihuaIntelligence` 文件夹。
2. 将新版源码解压到新文件夹，把原来的完整 `node-v24…-win-x64` 文件夹和私有 `.env.local` 复制过去。不要把 Node 的内容放进项目的 `node_modules`。
3. 双击 `START-WINDOWS.bat`。启动器会在依赖锁文件变化时执行 `npm ci`，随后执行兼容性迁移，再启动网站。保留原有用户数据目录。
4. 出现 Ready 后打开根页面 `/` 使用升级后的客户发现功能；市场情报页仍是 `/intelligence`。

原有 Windows 安装版程序没有重新打包，本次下载物是升级后的网页项目源码。

## 密钥在哪里配置

在运行网站的那台电脑上双击 `CONFIGURE-API.bat`，打开私有 `.env.local`。

- `SERPAPI_API_KEY`：继续使用现有 SerpAPI 密钥，默认同时用于 Google、Yandex 和 Trends。管理地址：https://serpapi.com/manage-api-key 。账号是否支持 Yandex、是否有额度，需真实请求验证；系统不自动购买套餐。
- `YANDEX_SERPAPI_KEY`：可选的另一枚 **SerpAPI** 密钥，只用于 Yandex。不填时复用上面的密钥。
- `YANDEX_API_KEY`：当前未选用 Yandex Cloud 直连方案，不读取该变量；不要误把 Yandex Cloud 密钥填进 SerpAPI 字段。
- UN Comtrade 公共预览不需要 `UN_COMTRADE_API_KEY`。付费海关、ITC Trade Map 和企业级贸易 API 需另行授权、实现适配，尚未接通。

配置助手只补充缺少的变量名，保留已有值；兼容常见 Windows BOM/编码情况，不回显密钥。保存后关闭并重新启动网站。网页只显示配置状态，不显示密钥。不要把密钥发送到聊天、粘贴进搜索框或提交到 Git。

## 新功能入口

- 原搜索框下方：`Search engines & public-source discovery`，选择 Google、Yandex 或双引擎，设置语言、平台、产品、地区ID、数量上限和超时。
- 建议词根据国家提供英语、俄语、波兰语或土耳其语，可自行修改。
- `B2B evidence filters & import/export`：按已核实城市、评级、证据覆盖率、WhatsApp/社交账号、人工核实官网和企业进口文件筛选，支持 CSV/Excel。
- `Search tasks, errors & API usage`：查看持久化任务、每引擎错误、缓存、请求尝试次数，恢复查询/筛选，取消排队或手动重试。
- 点击客户详情，再展开 `Multi-platform contacts, evidence & import analysis`：查看所有公开联系证据、业务推断、评分、来源及历史，进行人工核查或同公司合并。
- 原设置页面底部：调整六项 B2B 评分权重。

双引擎会并行请求，未缓存时通常每页2次查询；HTTP 5xx每个引擎最多重试一次。额度、认证和网络超时不会盲目自动重试。相同引擎查询缓存15分钟，每引擎新请求至少间隔2秒。调用次数不等于服务商实际计费额度。

## WhatsApp 的三个不同概念

1. **发现号码或链接**：来自具体公开来源。
2. **格式有效**：符合可能的国家区号和号码长度规则，不代表号码实际分配、注册或可达。
3. **人工核对归属**：业务员填写核查人和方法；仍不表示系统验证了 WhatsApp 账号注册或消息送达。

普通电话始终标为 WhatsApp 未确认。没有来源、不确定归属或格式不明时，不会凭空生成可靠的直联号码。API失败会单独显示，不会被记成“成功查过但没有号码”；历史号码保留。

可重新查询 WhatsApp、官网、Instagram、Telegram 和更多联系方式。社交平台仅使用合法公开搜索索引，不假设能读取私密账号或所有联系按钮。若勾选已确认官网并允许访问，系统最多访问4个内容页，并检查 robots、HTTPS、DNS/私网地址、访问挑战和页面大小；遇到限制停止，不绕过。云端代理环境会拒绝不支持的直接访问，保留索引模式。

## 评分与进口数据

默认权重：产品25、B2B业务20、WhatsApp20、OEM15、规模活跃度10、企业进口记录10。索引文字是推断，不能当作已证实事实；缺失项得0分并降低覆盖率，不重新归一化以抬高分数。覆盖率不是统计概率。

A≥80、B≥60、C≥40、D<40。客户规模、实际采购需求和预算在没有公开证据时保持未知。目录榜单、群组等研究资源保存在任务中，不直接当作公司；旧记录不删除，必要时人工核实官网后继续研究。

进口分析可查询国家层面的3—5年广义毛发制品贸易背景、可用数量/单位、同口径同比和返回的供应伙伴样本。HS候选编码仍待海关核实；胶水、工具、卸除剂和混合套装不能套用同一假睫毛分类。缺失数据不填零，分类版本变化时不计算误导性同比。

国家数据不是企业进口额。没有企业对应记录时显示“暂无企业级进口数据”。只有人工核对了明确关联公司的公开/授权文件后，才单独登记金额、数量、来源及核查依据；应用不会独立认证你输入的文件，也不会根据粉丝数、网站流量或公司规模猜进口量。

## 本地命令与部署

```sh
npm ci
npm run db:migrate
npm run dev
```

保留已有 `.env.local`，不要用示例覆盖真实密钥。服务器生产部署：使用外部 PostgreSQL 的 `DATABASE_URL`，移除 `DESKTOP_DATA_DIR`，运行迁移、`npm run build` 和 `npm start`。生产启动器使用 Next standalone 输出并准备静态资源。需要持续运行的 Node 服务和受保护访问；当前继承的应用没有登录/租户隔离，不宜将真实客户库直接公开。

任务队列是应用内持久化队列，应用服务运行时执行，不是已部署的外部调度服务。多实例或 serverless 部署应另配独立队列/worker。

## 验收边界与真实示例

自动化成功测试使用明确标注的合成响应，不是实时市场数据。云端没有可用 SerpAPI 密钥，服务网络访问也受限，所以本次不会伪造真实成功搜索样例。

在你本机用现有密钥成功查询后，打开任务面板，点击 `Export stored search example`，可导出那次实际保存的查询、引擎、原始链接、采集时间与结果，无需导出密钥。
