# Windows 真实市场数据配置

## 先配置，不要在聊天中发送密钥

1. 如密钥曾发到聊天，请到 SerpAPI 账户重置，使用新密钥。
2. 在最新版项目目录双击 `CONFIGURE-API.bat`。它会打开本机 `.env.local`，保留已有配置，必要时新增空的 `SERPAPI_API_KEY=` 行。
3. 在等号后粘贴你自己的密钥，不能有多余空格、换行或前导 `#`，保存文件。不要将密钥写入任何源代码、浏览器前端或 Git。
4. 关闭原来的项目命令窗口，重新双击 `START-WINDOWS.bat`；刷新网页。
5. 进入 `Data Sources / 数据来源`。密钥配置只显示“存在/未配置”，不会回显；存在密钥不代表认证成功。

## 查询 Google Trends

选择 Google Trends、国家、产品、关键词（可留空以使用产品名）、时间范围，然后点击“Collect real data / 采集真实数据”。

- 使用 SerpAPI 的 `google_trends` 引擎和 `TIMESERIES` 数据类型，按需消耗你账户的查询额度；不会自动购买或充值。
- 成功后数据会保存在数据库中，在 Products 产品分析页查看；按国家、产品、时间和来源筛选。
- 每条数据都有来源链接、采集时间、查询方法和限制。相同查询缓存15分钟，新查询每个数据源间隔60秒；不会后台自动采集。
- Google Trends 是查询范围内归一化的0–100搜索热度，不是销量、销售额或搜索绝对次数。不同国家、时间范围、关键词不能直接比较为市场大小。缺失、低于1和部分周期的数据不会被伪造为0。
- 结果为空不代表没有市场；API报错不代表销量为0。密钥错误、额度不足、网络失败和超时会明确提示。
- 不会自动将这些观测写进演示国家评分模型，也不会凭指数生成真实销量预测。

## 查询 UN Comtrade

选择 UN Comtrade、国家、已结束的年份、HS大类，然后采集。使用官方公开 preview 接口，不填入 SerpAPI Key，也不自动开通付费海关服务。

- HS 670419、670420、670490 属于多种毛发制品类别，涵盖假发等其他商品，不能认定为假睫毛专属进口数据。
- 页面保留服务返回的商品描述、分类版本、报告状态、统计年份和原始查询链接，金额显示 USD。
- 本接口只读取各国对世界的年度进口汇总，严格检查国家/伙伴/流向/年份/编码，不重复相加，也不写入产品销量图或评分。
- 公开接口有500行上限及服务自身限制；无记录仍为未知而不是0，连接失败也不会生成数据。

## 更新项目

本机数据在 `%LOCALAPPDATA%\BaihuaIntelligence`，不在代码文件夹。更新前关闭项目窗口、备份该目录以及本机 `.env.local`。新版代码中没有你的密钥。保留完整 `node-v24...-win-x64` 免安装运行时文件夹；下载新版到新目录时可将该文件夹移动到新版启动文件旁，然后重新配置 `.env.local`。

## 开发验证与限制

运行 `npm run lint`、`npm run typecheck`、`npm test`、`npm run build`。`tests/live-sources.test.ts` 使用明确标记的合成API响应验证解析、鉴权错误、空结果、缓存、限速和来源保存，不代表执行了真实市场查询。

浏览器配置与操作测试为 `tests/browser/live-sources.spec.ts`，UI成功响应使用拦截的合成样本，避免消耗用户账号额度。真实账号的认证和配额必须由你在本机配置密钥后执行一次真实请求确认。

云端本次未配置真实密钥。云端网络策略曾返回 CONNECT 403；已保存 serpapi.com 和 comtradeapi.un.org 的网络域名草稿，但这不代表运行时已开放，也不代表你的Windows电脑已经配置成功。Windows使用本机的网络和密钥，不受云端草稿自动配置。
